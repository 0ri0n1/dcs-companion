# Project and third-party material

This repository starts as a private source repository. A project licence has not
been selected; no open-source licence grant is made by this notice. Select and add
the intended licence before a public release.

DCS World, aircraft modules, terrain data, manuals, mission archives, virtual
display drivers, and the optional DCS Fiddle bridge are not bundled. Install
external components separately under their own terms. Generated navigation and
binding catalogues stay on the user's computer.

Python and JavaScript dependency manifests identify packages installed during
setup. Those dependencies retain their own licences. This repository contains
source and lockfiles, not copies of installed dependency trees or driver binaries.

DCS Companion is an independent project and is not affiliated with Eagle Dynamics.
